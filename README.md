# LinguaPro — Образовательная платформа с тестами

Итоговый проект: интерактивная веб-платформа для проверки знаний английского языка. Создана на чистом JavaScript (ES6-модули) с использованием HTML5, CSS3 и LocalStorage.

## 📋 Описание функционала
* **4 уровня сложности:** Beginner, Intermediate, Advanced, Expert. В каждом ровно по 20 уникальных вопросов (всего 80).
* **Таймер:** На прохождение одного теста дается 15 минут. По истечении времени тест завершается автоматически.
* **Прогресс-бар:** Наглядно показывает, на каком вопросе находится пользователь.
* **Мгновенная проверка:** При выборе ответа правильный вариант подсвечивается зеленым, неправильный — красным.
* **Сохранение результатов:** Лучший результат для каждого уровня сохраняется в `localStorage` браузера и отображается в меню.
* **Современный UX/UI:** Светлый минималистичный интерфейс (вдохновлен платформой EF SET), адаптированный под мобильные устройства.

## 🛠 Технологии и архитектура
* HTML5 (семантическая верстка)
* CSS3 (Flexbox, CSS-переменные, анимации)
* Vanilla JavaScript (ES6+)
* Архитектура: разделение логики на модули (`QuizManager.js`, `data.js`, `main.js`).

## 🚀 Как запустить локально
1. Откройте проект в VS Code.
2. Нажмите правой кнопкой мыши на `index.html` и выберите **"Open with Live Server"**.
*(Из-за использования ES-модулей проект не запустится при открытии файла двойным кликом).*

## 🤖 Использование нейросети
* **Нейросеть:** При выполнении задания использовалась нейросеть **DeepSeek**.
* **Что сделано с помощью нейросети:** Генерация банка вопросов, написание базовой логики класса `QuizManager` (таймер, переключение вопросов), создание CSS-дизайна на основе референса (EF SET).
